# Yeragorla Chandrababu — Portfolio

Personal portfolio website for Yeragorla Chandrababu.

## Tech

- HTML5
- CSS3
- JavaScript
- GitHub API
- GitHub Pages

## Features

- Responsive design
- Dark / Light mode
- GitHub repository integration
- Mobile navigation
- Animated hero section
- Experience timeline
- Projects section
- Skills section
- LinkedIn integration
- No framework
- No build step

## Run locally

Simply open:

index.html

Or use VS Code Live Server.

## Deploy to GitHub Pages

Create a repository:

YeragorlaChandrababu.github.io

Push the project to the `main` branch.

Then:

Settings
→ Pages
→ Build and deployment
→ Deploy from a branch
→ main
→ / (root)
→ Save

Your portfolio will be available at:

https://YeragorlaChandrababu.github.io/
